# פרומפט להדבקה ב-Claude Code

אתה עובד על אתר SYSTM. התיקייה כבר מכילה אתר רב עמודים עובד, תוכן בעברית, נכסי מותג ואפיון. קרא קודם את START-HERE-HE.md ואת docs/01 עד docs/11. אם נפתחת רק תיקיית site, המסמכים נמצאים בתיקיית האב.

המטרה: להשלים, ללטש ולהכין להשקה אתר ברמה חזותית וטכנית גבוהה מאוד עבור SYSTM — סוכני AI, אוטומציות, ייעוץ והדרכות בהובלת אריאל יהודה איזנשטט.

הרפרנס לחוויית הגלילה ולרמת הגימור: https://www.amichai-ai.co.il/ . הוא אינו מקור להעתקת טקסט, תמונות או מיתוג. הזהות היא SYSTM: שחור מט #080C0E, לבן #F5F7F7 ותכלת #ACF4F8, לוגו וקטורי מצורף וגופן Heebo.

הדגש החשוב ביותר: שימור אפקט blur reveal בכל עמוד, כולל עמודי שירות, מאמרים, אודות וקשר. בסיס המימוש כבר נמצא ב-src/motion.js: blur(8px), opacity:0 → blur(0px), opacity:1, משך 800ms ease-out, סף נראות 30%, הפעלה חוזרת בכניסה מחדש. יש כיבוי תנועה והעדפת reduced-motion. אין להחליף זאת ב-slide/fade גנרי בלבד, ואין לטשטש טפסים פעילים או את body.

דרך העבודה:
1. בדוק את מבנה התיקייה ואת הקוד הקיים לפני שינוי. הפעל npm run dev והכר את העמודים.
2. שמור על 18 המסלולים, ה-RTL, הלוגו, משפחת הגופנים והקופי המקורי. אין להתחיל מחדש מתבנית גנרית.
3. בדוק דסקטופ ומובייל בפועל. תקן overflow, חיתוכי טקסט, אזורי לחיצה, תפריט, פוקוס, שמירת מצב בטופס, FAQ, חיפוש ומעברי עמודים.
4. בדוק Reveal בירידה, בעלייה, בחזרה בדפדפן, בקישור למקטע ובמצב reduced-motion. פרק בלוק ארוך שלא מגיע ל-30% נראות.
5. ודא שכל CTA מוביל ליעד אמיתי. במחסור בפרט עסקי, שמור אותו בקונפיגורציה או ברשימת השלמות; אל תמציא נתונים ואל תציג placeholder לציבור.
6. אל תיצור המלצות, לוגואים של לקוחות, מספרי הצלחה או מבצעים שלא נמסרו.
7. טופס במצב WhatsApp מכין הודעה ואינו טוען שנשלחה. אם מחברים webhook, יש לאמת קליטה ביעד, להציג שגיאות אמיתיות ולעדכן מדיניות פרטיות ותוכן הטופס.
8. השלם SEO לפי דומיין אמיתי. אין להסיר noindex בלי להגדיר דומיין ולבדוק את הכתובות.
9. הרץ npm test, בצע בדיקות דפדפן, תקן כשלים ורשום תוצאות ב-QA-REPORT.md. אל תדווח על בדיקה שלא רצה.
10. מסור קוד מלא והוראות הרצה ופריסה. פרסם רק כאשר מתקבלת בקשה לפרסום או כאשר הדבר כלול במפורש בהנחיות המשתמש.

אין צורך לשנות framework בשביל רמת גימור גבוהה. הבסיס הוא HTML/CSS/JS עם Node builder ואפס תלויות צד שלישי. אם דרישה חדשה מחייבת React/Next.js או CMS, הסבר את הצורך ושמור את העיצוב, הכתובות, התוכן ומערכת התנועה.

בצע את העבודה בפועל עד שהאתר מוכן לבדיקה ולהשקה, ואל תסתפק בהצעת תוכנית.
