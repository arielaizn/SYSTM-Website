# בדיקות קבלה

## פקודה

מתיקיית site: `npm test`. הבדיקות בונות את dist ובודקות קישורים ומדיה, שפה ו-H1, אימות שדות בשרת ותשובות API במקרי הצלחה וכשל עם ספק מדומה מקומי. הן אינן שולחות פנייה לגורם חיצוני.

## בדיקה חזותית

- [ ] 320/390px: אין גלילה רוחבית או כותרת חתוכה.
- [ ] 768px: רשתות וכפתורים מתאימים לטאבלט.
- [ ] 1366/1440px: יחס בין טיפוגרפיה, תמונה ורווחים מאוזן.
- [ ] כל עמוד נפתח ישירות בכתובת שלו.
- [ ] הכותרות מתחדדות כשהן נכנסות למסך, וחוזרות להתחדד בכניסה חוזרת.
- [ ] כיבוי תנועה עובד ונשמר; העדפת מערכת מכובדת.
- [ ] במצב JS כבוי כל התוכן זמין וקישור קשר ישיר פועל.
- [ ] תפריט מובייל נפתח, נסגר ב-Escape ומחזיר פוקוס לכפתור.
- [ ] אין תמונות שבורות, מלל שנחתך או לינקים ריקים.

## תרחישי טופס

לנסות מעבר ללא שירות; להשלים שירות; לנסות שם ריק, טלפון קצר ואימייל פגום; לחזור שלב ולוודא ערכים; להשלים תיאור והסכמה; להכין הודעת WhatsApp ולוודא שאין הודעת הצלחה שקרית. במצב webhook לבדוק 200, 422, 403, 429, 502 ו-503 בתנאים מתאימים.

## לפני השקה

בדיקה באייפון Safari ואנדרואיד Chrome, זום 200%, מקלדת, לפחות קורא מסך אחד ובדיקה בפועל של יצירת קשר. לבצע ריצת Lighthouse ולשמור דוח אחרי פריסה. פרטי קשר, מדיניות פרטיות ותוכן מסחרי חייבים להתאים למצב הסופי.
